A Fellow Townsman Arrives v1.1.9 — Legacy size cleanup, report font correction and perennial hatchet rules

Six retired _large IDs and the retired small Parsnip are no longer registered as separate cheat/native item-catalog entries.

Historical save IDs resolve to the corresponding current regular crop, then follow the existing size/value/remaining-calorie migration. Seven legacy textures remain for the historical loading stage and do not create extra spawnable items. Existing saved produce is retained.

2. Correct night-report text size
The installed game's actual StartOfDayTMPPrefab stores fitted font size 15, base/max size 24, with auto-sizing enabled.
v1.1.8 incorrectly froze 15. v1.1.9 uses the native auto-size maximum of 24; longer reports wrap and scroll instead of shrinking to fit. Text already enlarged by another font mod is not forced back down.
The ledger frame/footer, native/other-mod report entries and numbers remain. Font Scale Mod, the night theme and their settings are not edited.

3. Established perennials still require a hatchet
Stop after harvest remains off by default. When enabled it finishes the current harvest, then blocks regrowth and replanting.
Stopping no longer lets an established perennial be dragged out as a refunded seed. Changing crops still requires the native hatchet to clear the plant, without returning a seed.
Turning the control off resumes a retained plant on its regrowth cycle. Unplanted seeds retain their native removal rules.
This covers added plants, native Bloomberry and plants edited to become perennial. Clearing uses the original native hatchet implementation.
