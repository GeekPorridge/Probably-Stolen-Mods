# 星露谷扩展 2.0.4

1. 修复养殖产物栏一直为空。原版界面会将库存包装在 `MachineryIntake` 中，旧代码直接强制转换外层，导致找不到产物库存，生成的鸡蛋、奶和松露无法落格。现在使用原版库存遍历接口，并阻止读档、早晨初始化时重复添加空产物栏。
2. 读档时修复旧版重复产物栏引起的饲料机、宰杀机及产物存储索引错位。保留物品身份、数量和动物状态，不补发历史未生成的产物。鸡和山羊的产物确实放不下时，夜报也会记录。
3. 针对牛、猪、鸡、山羊加入异常零体重保护：保留最近有效体重；旧档没有有效记录时按原版对应成长阶段的最低体重恢复。正常正数掉重保留，健康、疾病、饥饿和死亡状态不更改，也不为零重尸体生成肉量。当前玩家存档未复现患病自动变零的触发过程；已验证零值及非法值修复路径。
4. 白酒沿用 2×3 格。旧存档在完整库存加载后修复占格；放不下时安全保留旧占格，腾出位置后自动重试。等待扩容的提示现在会显示，说明适用于白酒和啤酒。
5. 白酒不再随原版过夜、陈酿架或直接陈酿回调升值，也不再显示陈酿提示。旧存档已经获得的价格与酒龄保留，不追溯扣除；将瓶子重新用于果酒时恢复果酒陈酿功能。
6. 加固运行状态判断，使用实际玩家存档和已创建的店铺库存。阅读、首次过夜、夜间出行入口检查初始化，读档及出行前检查水库注册。手册和夜间地图已验证当前存档可用，未覆盖所有旧档状态。
7. 食用蛋改为 1×2 格，蛋黄酱改为 2×2 格。重新从原始贴图导出对应尺寸，保留比例和透明背景。旧物品安全迁移，空间不足时保留物品并等待重试；迁移不合并物品栈。

饲料说明：冰淇淋属于非植物食物，不能作为牛、山羊和本模组鸡的植物饲料。机器“总热量充足”和“有适口植物饲料”是两个条件；猪可以使用这部分非植物食物。请加入小麦、玉米、营养果等植物食物，并启动混合或开启自动混合。已明确记录的非植物食物不会被改成植物饲料。成年、健康、饱食及产出间隔条件仍然生效。

更新后完整退出并重新启动游戏，只启用一份 `pelican_cultivation`。缺失的历史夜报不会根据今天的动物状态伪造；修复后的报告从下一次正常过夜结算开始生成。作弊菜单的“跳过天数”只修改日期，不执行生产、服务或夜间结算。

自动血清和自动清粪沿用玩家现有设置。养殖报告中的机器信息按实际设备和当晚状态显示。夜行者仍为 1.1.1，本次无需重新安装。

验证记录见发布包的“实机验证.md”和自动回归日志。原始玩家存档已提前备份，测试后恢复原进度；测试物品和结算结果不进入玩家原存档。
