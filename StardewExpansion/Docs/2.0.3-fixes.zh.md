# 星露谷扩展 2.0.3 / 夜行者 1.1.1

1. 自养牛、猪、鸡、山羊、海参、龙虾及新增鱼类的屠宰产物继承动物归属，避免变成“未拥有”物品而被柜台接收、自动屠宰机拒收。读档时重新绑定已有产物栏的访问规则，使用当前笼子的归属状态。旧饲料兼容处理也避免母鸡因无法吃到旧储料而停止产蛋。
2. 啤酒和其他自制酿品的显示名按实际酿品种类解析，避免保留原版 Bloomberry wine 名称；优先显示玩家自己设置的物品名。
3. “Shift 查看描述”是第三方“物品详情美化 · Better Item Tooltips”的默认折叠设置。其设置中保持“显示描述”开启，关闭“收起描述”（CollapseDescription），即可直接显示。星露谷扩展的工坊包不会覆盖其他模组的全局偏好；本机配置已核实为显示描述、关闭描述折叠。
4. 降低夜钓四种普通鱼的可收获肉量。满养成年个体的基准上限：午夜鲤鱼 600、大嘴鲈鱼 900、金枪鱼 1600、岩浆鳗鱼 1200 千卡。实际按体重及已有可用肉量取较低值；老年体重增加时按比例变化。日常维持消耗不会无限转成肉。规则同样作用于旧存档的这些鱼和待分解鱼尸。鱼王与原版鱼不受此项调整影响。
5. 受精鸡蛋取消禁止取出的回调，可以移动、取出、放回和参与正常整理。继承基因和两晚孵化规则保留；孵化仍只在动物笼中推进。
6. 启用“低免疫／普通疾病自动使用绿色血清”后，夜间疾病判定前逐只检查，优先处理已患病动物，同时覆盖免疫低于物种阈值的动物。消耗主背包或仓库中真实药剂次数，不重复注射仍有药效的动物。血清仍按原版增加免疫和食量，不直接清除疾病或朊病毒。
7. 跳过剧情后，不再等到初始物品／晨报界面触发初始化；游戏场景就绪后和第一次睡觉前均补充检查。因此前几晚也能开始动物报告、成长预测、疫病处理和粪便服务。
8. 夜行者单独更新为 1.1.1：恢复读档时未保存的自定义图标键，避免状态页回退到默认图标。

饲料报告同步修正：旧存档缺少植物来源记录的非肉饲料只兼容迁移一次，不增加总热量；已有明确分类的储料保留原分类。喂食和预测读取同一份分类。混养时部分动物吃不到现有储料会说明食性不匹配，不再仅用“有大量热量、约0晚”表示；不足 0.1 晚的正数显示为 <0.1。

使用当前本机游戏程序集构建。已运行隔离的原生方法回归、双语资源检查和游戏内置模组扫描器；具体结果见发布包内验证报告。渲染和场景边界使用测试替身，未打开或修改玩家存档，未做游戏内逐项实机验收。已消失或已经售出的旧物品不由补丁重建。
